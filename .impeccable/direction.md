# Direction contract

Mode: Operate. Build path: code, explicitly confirmed. Brand: dark with #004225 forest green, pinned by the user. Working name: Button Copy.

The product is a manually assembled collection of live button specimens. The library's first viewport should show the buttons themselves at readable size, with source and capture notes beneath. A permanent left rail keeps collection filters and backup tools separate from the main choose/export flow. Selection is quiet and consistent. Details open beside the collection and expose interaction states and reusable code.

The grounded structures considered were a file browser, a component explorer, a specimen collection, a style inspector, a contact sheet, a saved-items reading list, and a side-by-side comparison workbench. The concept seed assigned the specimen collection, index 3. Dark material and forest controls translate the specimen concept into the user's pinned palette.

The signature interaction is a real button in an isolated interactive viewport, followed by explicit state controls. Preserve original button colors. Metadata must never look like proof of guaranteed capture. Capture notes stay findable from every specimen. The empty state explains the manual capture flow instead of inserting synthetic saved content.

Risks: collecting specimens resembles a familiar asset library; it is chosen for clear operation. Small viewport previews must not silently activate unrelated responsive rules. Native controls and predictable keyboard focus outrank decorative motion. Inspect at desktop 1440 and compact desktop 900 plus the toolbar popup.
