# Button Copy

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Plain HTML, CSS, and JavaScript, confirmed by the user. Desktop WebExtensions with Chromium and Firefox packages, and Safari conversion instructions.

## Users

People collecting reusable website buttons. Specific professional roles are undecided.

## Product purpose

The user manually selects a website button, stores its appearance and available states locally, previews the capture, and exports one or several buttons as HTML, CSS, and JavaScript.

## Capabilities and constraints

Capture descendant content, fonts, icons, pseudo-elements, interaction states, CSS transitions, keyframes, and available Web Animations data. Include responsive rules where readable. Save incomplete captures with specific warnings. Arbitrary website application logic cannot be extracted reliably. Desktop only. No account or sync in the first release.

## Brand commitments

Dark interface with #004225 deep forest green. Captured buttons retain their source styling. The user requested building directly in code.

## Product principles

- Copying starts only after the user chooses a button.
- Captures remain on this device until the user exports them.
- Show limitations beside the affected capture.
- Exports include the assets successfully embedded in the capture.

## Evidence on hand

An empty project and the user's feature brief and confirmed answers. No supplied name, logo, customer research, or example websites. Button Copy is a working name.
