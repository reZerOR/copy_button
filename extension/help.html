Button Copy

Capture a button

  1. Open a regular website in a desktop browser.
  2. Click the Button Copy toolbar icon, then Choose a button.
  3. Point at the button and click. This selects the element without running its normal website action.
  4. Move your pointer to the picker toolbar and click Save button. The extension reads its default styling, matching CSS states, animations, and assets.
  5. Open the library to compare the live preview, try states, and read capture notes.
  6. Select one or several buttons and export a ZIP containing HTML, CSS, JavaScript replay, and notes.

Custom buttons and frames

Hold Alt while clicking to select a custom element. Select parent expands the outline when an icon or label is only part of the button. For a button inside an embedded frame, open that frame's URL in its own tab and capture there.

Assets and fidelity

Stylesheets, fonts, and images on other domains may require access. The detail view offers Allow resources and retry for the specific affected domains. If a stylesheet was unreadable, recapture after granting access to recover its state rules. Some servers reject downloading assets even with access.

Capture notes describe limits. Arbitrary website JavaScript, closed shadow roots, canvas drawing code, scroll triggers, and every possible responsive context cannot be guaranteed. The default style is a snapshot at the source viewport. Source CSS states, transitions, keyframes, and available Web Animations are included when readable.

Privacy and backups

Buttons are stored in this browser's local extension storage. No account, analytics, or upload service is used. Assets are downloaded from their source servers during capture. Back up the library before removing the extension, clearing its data, or changing browsers. Imported previews run in isolated frames, and executable website markup is removed.
